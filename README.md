# Tableau de bord BTP – Projet fictif

Ce projet est un **dashboard fictif** réalisé dans le cadre d’un apprentissage en data visualisation.  
Il simule l’analyse d’activité d’une entreprise du secteur du BTP afin d’illustrer la création d’un tableau de bord professionnel.

---

## 📊 Fonctionnalités

- **Chiffre d’affaires total** : 1,43M€
- **Répartition des clients** :
  - 36% Particuliers
  - 64% Entreprises
  - 100 clients au total
- **Note de satisfaction** : 7,07 / 10
- **Évolution du CA mensuel** (2019–2022)
- **Top 5 clients** :
  - ZARA
  - TATI OR
  - Xavier DAUDET
  - Xavier GEBRURT
  - Xavier LEMPIKA
- **Filtres disponibles** :
  - Année
  - Type de client
  - Type d’intervention (Carrelage, Gros œuvre, Peinture, Plomberie, Ramonage, Rénovation)
